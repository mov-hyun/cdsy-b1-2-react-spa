# Supabase 실제 연결 검증

검증일: 2026-10-05 (Asia/Seoul)

## 환경

- 과제 전용 Supabase 프로젝트: cdsy-b1-2-react-spa
- 지역: Northeast Asia (Seoul)
- 학습 기록 테이블, 소유자별 CRUD RLS, 수정 시각 트리거 적용
- Anonymous Sign-ins 활성화 (사용자 승인 후 적용)
- 브라우저용 publishable key와 Project URL을 Git에서 제외한 .env.local에 설정

## 원격 API 검증

`npm run test:remote`가 실제 Supabase에 연결되어 다음 항목을 통과했습니다.

1. 임시 학습 기록 등록
2. 목록 및 상세 조회
3. 제목과 상태 수정 후 재조회
4. 다른 사용자로 동일 기록 조회·수정·삭제 시도: 접근할 수 있는 행 0개
5. 다른 사용자 소유자로 위조한 insert: 거부
6. 본인 기록 삭제 및 삭제 후 목록 조회: 해당 행 0개

검증용 데이터 행은 삭제했습니다. 테스트에서 생성한 익명 인증 계정 2개는 남아 있습니다. 기존 사용자 기록에는 접근하지 않았습니다.

## 실제 브라우저 검증

모의 API를 사용하지 않고 로컬 Vite 앱에서 확인했습니다.

- 최초 진입 시 익명 세션 생성, 빈 목록과 0개 통계 표시
- 폼에서 `[연결 확인] React와 Supabase 데이터 흐름` 기록 저장
- 저장 성공 알림 및 상세 경로 이동
- 수정 화면에서 내용을 수정하고 상태를 `이해 완료`로 변경
- 제출 중 필드와 버튼 비활성화 확인
- 상세 주소 새로고침 후 제목·내용·상태 유지 확인
- 브라우저 오류 로그: 0개

브라우저 확인용 기록 1개는 Chrome의 해당 익명 학습 공간에 남겨 두었습니다. 다른 브라우저와 배포 사이트는 각각 별도 익명 세션을 생성하므로 이 기록이 자동으로 표시되지 않습니다. 삭제 버튼의 UI 흐름은 기존 모의 API E2E로, 실제 삭제는 위 원격 API 검증으로 확인했습니다.

## 빌드 및 남은 범위

- 실제 환경변수 적용 후 `npm run build`: 성공
- 단일 JavaScript 번들 약 512 kB(압축 전)에 대한 Vite 안내가 있습니다. 빌드 오류는 아닙니다.
- GitHub 소스 업로드 및 Vercel 배포 전입니다.
- 배포 URL의 CRUD·직접 주소 접근·새로고침 검증은 배포 후 별도로 수행해야 합니다.

API 키, 세션 토큰, 비밀번호 및 사용자 개인 정보는 이 문서에 기록하지 않습니다.
